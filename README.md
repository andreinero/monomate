# MonoMate — free chess trainer for iPhone, Android, Windows and the web

## Download

- **Play in the browser:** https://monomate.pages.dev (on iPhone: Safari → Share → Add to Home Screen)
- **Android and Windows:** latest release at https://github.com/andreinero/monomate/releases/latest
  - `MonoMate-1.0.0.apk`: Android. Open it on the phone and allow installing from this source.
  - `MonoMate-Setup-1.0.0.exe`: Windows installer.
- **iPhone app:** installed from this Mac with Xcode (no App Store version).

Play bots, learn with a coach, solve puzzles and review your games — all free, all on-device.

## Features

| | |
|---|---|
| **Play Bots** | 9 original opponents from 250 to 2700 (Pip → Titan), each with its own personality. Pick White, Black or random. Hints, takebacks, rematch. |
| **Play with Coach** | Coach Sage evaluates every move you make, names the opening, warns about threats (hanging pieces, mate threats) and explains mistakes ("this leaves your knight on e5 hanging — Black can play dxe5"). After a mistake you can **Retry**, **Show better** or **Continue**. Live eval bar. |
| **Game Review** | Stockfish reviews the whole game: accuracy per player, estimated game rating, each move classified (Great / Best / Excellent / Good / Book / Inaccuracy / Mistake / Blunder), best-move arrows, best line, eval graph, jump to key moments, coach explanations for every move. |
| **Puzzles** | Rated puzzles (Elo-style rating), Daily Puzzle and Puzzle Streak. Live from the Lichess open database, plus a 60-puzzle offline pack. |
| **Analysis Board** | Play out any line, 3 live engine lines (depth 16), import PGN or FEN, launch a full review. |
| **Pass & Play** | Two players on one device. |
| **Me** | Stats, bots defeated, puzzle rating, board themes, settings. |

Everything (games, ratings, settings) is stored locally on the phone. No account, no ads, no server.

## Run it on your phone (free)

1. Install **Expo Go** from the App Store / Google Play.
2. On your Mac:
   ```bash
   cd ~/gambit-chess
   npm install
   npx expo start
   ```
3. Scan the QR code (iPhone: Camera app, Android: Expo Go). Phone and Mac must be on the same Wi-Fi.

Simulators: `npx expo start --ios` or `npx expo start --android`.

## Build the apps locally (free, no accounts)

`ios/` and `android/` are generated by `npx expo prebuild` — don't edit them by hand; change `app.json` instead.

**Android APK** (signed with the project's debug key — fine for sideloading, not for Google Play):

```bash
npx expo prebuild --platform android
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
cd android && ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a,armeabi-v7a,x86_64
cp app/build/outputs/apk/release/app-release.apk ../dist/Gambit-1.0.0.apk
```

Install on a phone: send the APK to it (AirDrop to a Mac → USB, Google Drive, email…), open it and allow
"Install unknown apps". Or with USB debugging: `adb install dist/Gambit-1.0.0.apk`.

**iPhone** (free Apple ID): plug the iPhone in with a cable, unlock it, then:

```bash
npx expo run:ios --device --configuration Release
```

First time only: on the iPhone enable *Settings → Privacy & Security → Developer Mode*, and after
install trust the developer under *Settings → General → VPN & Device Management*. With a free Apple ID
the app stops opening after 7 days — re-run the command to refresh it. A paid Apple Developer account
($99/year) removes that limit and allows TestFlight / App Store distribution.

App icons are generated by `swift scripts/make-icons.swift assets`.

## Build in the cloud with EAS

Uses [EAS Build](https://docs.expo.dev/build/introduction/) (free tier is enough):

```bash
npx eas-cli@latest login
npx eas-cli@latest build:configure
npx eas-cli@latest build -p android --profile preview   # .apk you can install / share directly
npx eas-cli@latest build -p ios                          # needs an Apple Developer account
```

Store costs (set by Apple/Google, not by this app): Google Play is a one-time **$25**; the Apple App Store requires the Apple Developer Program at **$99/year**. Android APKs can be shared for free without the store.

## Project layout

```
src/app/            screens (Expo Router)
  (tabs)/           Play · Puzzles · Analysis · Me
  bots.tsx          opponent picker
  game.tsx          bot / coach / pass-and-play game
  review.tsx        game review
  puzzle.tsx        puzzle trainer (rated / daily / streak)
src/engine/
  EngineProvider    runs Stockfish in a hidden WebView (works in Expo Go, no native code)
  uci.ts            UCI parsing
  analysis.ts       win %, move classification, accuracy, full-game review
  bots.ts           bot personalities and move selection
  coach.ts          coach explanations and threat detection
  openings.ts       opening names / book moves
src/components/     Board (tap + drag, arrows, promotion), eval bar, move list, eval graph
src/lib/            storage, puzzles API, theme
scripts/            asset generation, puzzle download, engine smoke test
```

Checks: `npx tsc --noEmit`, `npx eslint src`, `npx tsx scripts/engine-smoke-test.ts` (tests the engine, review, bots and coach against real Stockfish).
